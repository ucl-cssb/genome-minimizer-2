# Training summary

Per-variant training-loss figures and run-level statistics for the v0–v3 VAE
ablation ladder.

## Contents

- `v{0,1,2,3}_total_loss.png` — train vs validation total-loss curve, one PNG per
  variant (generated by `../figures.py`; `uv run python notebooks/figures.py`).
- `run_stats.csv` — run-level statistics (source of truth for the table below).

## Provenance

**Loss / epochs / overall metrics (all rows)** come from the UCL-CSSB canonical
W&B runs (the authoritative paper checkpoints), pulled into
`paper_figures/data/history/` via `run.scan_history()`. Each row's `source`
column gives the run ID; the values are the final logged epoch of that run's
history. These are the *same* per-epoch dumps the loss-curve PNGs are plotted
from — the final point of each curve equals the corresponding row here. Verify
any run in the W&B UI, e.g. `https://wandb.ai/ucl-cssb/Genome-Minimizer/runs/<id>`.
